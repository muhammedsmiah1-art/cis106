## What is Markdown?
Markdown is a way to format text using basic symbols like hashtags and asterisks. It was created so people could write plain text files that look organized and are easy to turn into HTML or formatted documents. It is really common in coding and documentation because it keeps things clean without relying on heavy word processors

## What is Git?
Git is a version control system that tracks changes made to files over time. It lets us save different snapshots of their project code, go back to older versions if something breaks, and work on new features without messing up the main program. It is essential for managing code history and working alongside other programmers

## What is GitHub?
GitHub is an online hosting platform built around Git. While Git handles tracking changes locally on your computer, GitHub gives us a place to store those repositories in the cloud so teams can share code, review each other's work, and collaborate. It also includes extra project tools like issue trackers and wikis

## What is Slack?
Slack is a messaging app similar to Discord that is designed for team communication and workspace collaboration. Instead of cluttering up emails or back to back DM's, discussions happen in chat rooms called channels and you can discuss about things like coding with each other. It also integrates with apps like GitHub to keep updates in one central place
